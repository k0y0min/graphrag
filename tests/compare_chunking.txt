GraphRAG (Graphs + Retrieval Augmented Generation) is a technique that combines knowledge graphs with LLMs. Instead of relying purely on vector similarity, it traverses relationships to find interconnected context. This is particularly useful for complex reasoning over large documents.

However, traditional chunking destroys relationships. If a sentence about "Elon Musk" is in chunk A, and "SpaceX" is in chunk B, the connection might be lost.

Perplexity chunking solves this by using the LLM's own causal matrix to find semantic boundaries. When the LLM is 'surprised' by a word (high perplexity), it implies a shift in context, making it a perfect place to split the chunk.

==== FINDINGS ====
- Fixed: strict token caps break semantic cohesion, so this is the weakest ingestion option here.
- Recursive: preserves local structure, but may still split related content in ways that are not intelligence-aware.
- Semantic: aggressively chunks resulting in individual sentence-chunks. Doesn't preserve inter-sentence realtions (breaking a coherent paragraph into well separated sentences is still bad).
- Perplexity: results in chunking only when a true context switch occurs or token limit is hit, resulting in intelligent chunks minimizing information loss(or faulty KG-triples) due to poor chunking.
